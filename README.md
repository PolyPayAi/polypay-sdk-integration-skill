# PolyPay SDK Integration Skill

AI coding skill for integrating PolyPay / PonponPay payments, hosted checkout,
SDKs, webhook verification, x402, and Notification Center templates.

## Install

### Codex

```bash
git clone https://github.com/PolyPayAi/ponponpay-sdk-integration-skill \
  ~/.codex/skills/ponponpay-sdk-integration
```

### Claude Code

```bash
git clone https://github.com/PolyPayAi/ponponpay-sdk-integration-skill \
  ~/.claude/skills/ponponpay-sdk-integration
```

For Cursor, Windsurf, Cline, GitHub Copilot, and Gemini CLI, copy `SKILL.md`
into the tool's project rules or custom instructions.

## Covers

- Hosted checkout
- JavaScript SDK / Public Key Mode
- PHP SDK / API Key Mode
- Webhook verification
- x402 payment flows
- Notification Center channels and templates
- Bilingual notification templates (`en`, `zh`)
- Wallet income/expense notifications (`wallet_transaction`)
